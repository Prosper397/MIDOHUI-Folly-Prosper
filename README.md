## ⭐ Projets

### 🎓 [FormationPro](https://github.com/Prosper397/FormationPro)
Plateforme full-stack de gestion de formations en présentiel, réalisée dans le cadre de mon **stage de 2e année à l'IAI-Togo**, pour l'entreprise **ITEBEMA SARL U** — inscriptions, paiement mobile (Moov Money, T-Money), création automatique de groupes, présence, quiz et certificats.
`Node.js` `Express` `TypeScript` `Prisma` `PostgreSQL` `React` `Flutter`
Architecture 3-tiers, RBAC + JWT, soft delete conforme RGPD, et un prototype d'assistant IA (RAG) intégré.
